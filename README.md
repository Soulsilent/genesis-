# Genesis2000 图纸排列与处理系统

> 基于 Python3 的 Genesis2000 自动化脚本与接口服务

## 📖 项目简介
本项目旨在通过 Python 实现 Genesis2000 的自动化操作，核心功能包括 PCB 图纸的自动排列（Panelization）、封边处理以及相关的 API 接口服务。项目采用模块化设计，将算法逻辑、UI 交互与后端接口分离，便于维护与扩展。

## ✨ 主要功能
- **图纸自动排列**：支持多种拼板策略，优化板材利用率。
- **封边自动化**：自动添加工艺边、Mark 点及辅助线条。
- **Python API 接口**：提供 RESTful 接口，支持外部系统调用核心算法。
- **模块化架构**：
  - `genesis_python3语法`：核心算法库。
  - `py接口`：后端服务层。
  - `封边/图纸项目`：具体业务逻辑实现。

## 🚀 快速开始

### 1. 环境要求
- Python 3.8+
- Genesis 2000 (需配置好环境变量)

├── genesis_python3语法   # 核心算法与底层语法封装
├── py接口                # Web API 接口服务
├── 封边项目              # 封边相关业务逻辑
├── 图纸项目              # 拼板与排版业务逻辑
├── gtw                   # 网关或工具组件
